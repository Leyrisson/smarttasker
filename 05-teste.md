# Plano de Testes para SmartTasker (Android)

## 1. Casos de Teste

### 1.1 Criação de Projeto
- **Descrição**: O usuário deve ser capaz de criar um novo projeto.
- **Resultado Esperado**: O usuário deve ver o novo projeto no painel principal.
- **Risco**: Falha na criação do projeto, não permitindo a inclusão de novos itens.

### 1.2 Visualização de Projeto
- **Descrição**: O usuário deve ser capaz de visualizar todas as tarefas do projeto.
- **Resultado Esperado**: O usuário deve ver todas as tarefas do projeto em uma lista.
- **Risco**: Falha na visualização das tarefas, não fornecendo o acesso a todas as tarefas.
